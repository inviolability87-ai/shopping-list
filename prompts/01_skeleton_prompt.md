# 1단계 프롬프트 — 기본 뼈대 작성

아래 PRD(`PRD.md`)를 참고하여 쇼핑 리스트 앱의 **기본 뼈대**만 작성해줘.
이 단계에서는 완전한 기능 구현 없이, 앱의 전체 구조와 레이아웃만 잡는 것이 목표야.

## 요청 사항
1. `app.py` 파일을 생성해줘.
   - Streamlit 앱의 기본 골격만 작성 (제목, 입력 영역, 리스트 표시 영역의 레이아웃)
   - `st.session_state`를 이용해 아이템 목록을 저장할 자료구조를 초기화 (예: `[{"text": str, "checked": bool}, ...]`)
   - 아이템 추가/삭제/수정/체크 기능은 아직 실제 동작 없이, 함수 스텁(빈 함수 또는 TODO 주석)이나 최소한의 placeholder UI만 배치
   - 실행 시 에러 없이 `streamlit run app.py`로 켜지는 것이 목표
2. `requirements.txt` 파일을 생성해줘.
   - `streamlit` 패키지 포함 (버전 명시 여부는 자유)
3. 코드에 불필요한 주석이나 과도한 설명은 넣지 말고, 다음 단계(기능 추가)에서 확장하기 쉬운 구조로 작성해줘.

## 완료 기준
- `streamlit run app.py` 실행 시 에러 없이 기본 화면(제목 + 입력창 + 빈 리스트 영역)이 뜬다.
- 아이템 추가/삭제/수정/체크는 아직 동작하지 않아도 된다.
