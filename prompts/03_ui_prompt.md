# 3단계 프롬프트 — UI 디자인

2단계까지 기능이 모두 동작하는 `app.py`를 기반으로, `PRD.md`의 "화면 구성(UI 개요)" 섹션에 맞게 UI/UX를 다듬어줘.

## 요청 사항
1. **레이아웃 정리**
   - 상단에 앱 제목 배치
   - 입력 영역(텍스트 입력창 + 추가 버튼)을 한 줄로 깔끔하게 배치 (`st.columns` 등 활용)
   - 리스트 영역에서 각 아이템이 체크박스 / 텍스트 / 수정 버튼 / 삭제 버튼 순서로 정렬되도록 구성
2. **완료 항목 시각적 구분**
   - 체크된 항목은 취소선 처리 또는 회색조로 명확히 구분되도록 스타일 적용
3. **가독성 및 여백**
   - 아이템이 많아져도 리스트가 보기 편하도록 간격, 정렬 정리
   - 빈 리스트일 때 안내 문구(예: "추가된 아이템이 없습니다") 표시
4. **버튼/아이콘**
   - 삭제/수정 버튼에 아이콘(이모지 등) 사용 가능 (예: 🗑️ 삭제, ✏️ 수정)
   - 버튼 크기가 리스트 텍스트와 어울리도록 정렬

## 주의사항
- 기능 로직(2단계에서 구현한 추가/삭제/수정/체크 동작)은 변경하지 말고, UI/레이아웃 관련 부분만 수정해줘.
- 과도한 커스텀 CSS나 외부 라이브러리 추가 없이 Streamlit 기본 컴포넌트로 최대한 구현해줘.

## 완료 기준
- PRD의 "화면 구성" 항목과 실제 화면이 일치한다.
- 완료된 항목과 미완료 항목이 한눈에 구분된다.
