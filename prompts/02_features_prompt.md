# 2단계 프롬프트 — 기능 추가

1단계에서 작성한 `app.py`의 기본 뼈대 위에, `PRD.md`의 기능 요구사항(F1~F5)을 실제로 동작하도록 구현해줘.

## 요청 사항
1. **아이템 추가 (F1)**
   - 텍스트 입력 후 버튼 클릭 또는 엔터로 `st.session_state`의 리스트에 새 아이템이 추가되도록 구현
   - 빈 문자열 입력 시 추가되지 않도록 처리
2. **아이템 삭제 (F2)**
   - 각 아이템 옆에 삭제 버튼을 배치하고, 클릭 시 해당 아이템만 리스트에서 제거
3. **아이템 수정 (F3)**
   - 각 아이템의 텍스트를 수정할 수 있는 UI(예: 수정 버튼 클릭 시 입력창으로 전환) 구현
   - 수정 완료 시 리스트에 변경 내용 반영
4. **아이템 체크 (F4)**
   - 각 아이템에 체크박스를 배치하고, 체크 여부를 `st.session_state`에 저장
   - 체크된 항목은 텍스트에 취소선 처리 등으로 구분 (세부 스타일은 3단계에서 다듬을 예정이므로 최소한의 구분만 적용)
5. **세션 상태 유지 (F5)**
   - 리스트 조작(추가/삭제/수정/체크) 후에도 `st.session_state` 기반으로 상태가 올바르게 유지되는지 확인
   - Streamlit의 rerun 특성을 고려해 위젯 key 충돌이나 상태 꼬임이 없도록 처리

## 주의사항
- 기존 뼈대 구조를 크게 바꾸지 말고, 그 위에 기능을 채워 넣는 방식으로 작업해줘.
- 각 기능은 PRD의 성공 기준(추가/삭제/수정 시 즉시 리스트에 반영, 체크 시 시각적 구분)을 만족해야 해.
- 불필요한 예외 처리나 없는 시나리오에 대한 방어 코드는 추가하지 마.

## 완료 기준
- 아이템을 추가/삭제/수정/체크했을 때 PRD의 "성공 기준" 항목이 모두 충족된다.
